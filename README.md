# حَرف | HARF

إنسان · حيوان · نبات · جماد · بلاد — لعبة جماعية للعائلة والأصحاب، كل واحد يلعب من جهازه.

من **WAMD ARC** · [wamdarc.com](https://wamdarc.com) · [harf.wamdarc.com](https://harf.wamdarc.com)

## الفكرة
- **أي أحد** ينشئ لعبة: تاخذ **رقم** (#) و**اسم** و**كود سري** من ٦ أرقام، والباقين يدخلون بالكود أو بمسح الباركود.
- العجلة تختار الحرف (وما يتكرر في نفس اللعبة)، وكل لاعب يكتب في جهازه.
- «ستوب!»: أول واحد يكمّل كل الخانات يوقف الجولة، والباقين لهم ٥ ثواني. أو «لين يخلص الوقت».
- التصحيح فئة فئة: فريدة ١٠، مكررة ٥، والإجابة المختلف عليها تتصوّت والمضيف يحسم.
- وقت إضافي لأي لاعب (للصغار)، والكتابة بالصوت.
- كل لعبة تبقى في **السجل** برقمها واسمها ونتيجة كل جولة وإجاباتها.
- **على ورقة**: بدون نت، يطلع الحرف ويشغّل الوقت ويجمع النقاط.

## الملفات
| الملف | وظيفته |
|---|---|
| `index.html` | الواجهة والتصميم (هوية ومض آرك: سماء تذوب في الرمل، ألواح زجاجية، برتقالي) |
| `config.js` | **رقم الإصدار، ورابط السيرفر، وإيميل التواصل** |
| `app.js` | الرئيسية، الإنشاء والدخول، اللعبة الجماعية، التصحيح، السجل، الورقة، الإعدادات |
| `qr.js` | صانع الباركود (qrcode-generator، رخصة MIT) |
| `sw.js` | العمل بدون إنترنت والتحديث التلقائي |
| `privacy.html` | سياسة الخصوصية (عربي وإنجليزي) |
| `wamd-stats.js` · `wamd-cfg.js` | عدّاد الاستخدام ورسائل لوحة الإدارة (مشتركة بين تطبيقات ومض آرك) |
| `worker/worker.js` | السيرفر `harf-api` (Cloudflare Worker + D1 باسم `harf`) |

## النشر
- **التطبيق:** GitHub Pages من `main` على `harf.wamdarc.com` (ملف `CNAME`).
- **السيرفر:** Cloudflare Worker باسم `harf-api` مربوط بهذا المستودع (Workers Builds)، أي رفع على `main` ينشر `worker/worker.js` حسب `wrangler.toml`.
- **قاعدة البيانات:** D1 باسم `harf`، والجداول تنشأ لحالها أول طلب.

## مع كل تحديث
غيّر `VERSION` في `config.js` و `VERSION` في `sw.js` و `?v=` في `index.html`. الأجهزة تتحدّث لحالها (وما يعيد التحميل وسط جولة).

## كيف يشتغل السيرفر
- كل جهاز ياخذ مفتاح (token) خاص فيه، وما أحد يشوف إجابات غيره وقت الكتابة.
- الجهاز يسأل `/state` كل ثانية تقريباً، والسيرفر يرد `{same:1}` إذا ما تغيّر شي (قراءة صف واحد).
- الإجابات تنحفظ كل ثانية ونص وقت الكتابة، والجولة تنقفل لما الكل يسلّم أو يخلص وقته (مع الوقت الإضافي).
- المضيف إذا طلع أو غاب دقيقة، الإدارة تنتقل لغيره. الكود ينتهي مع نهاية اللعبة أو بعد ١٢ ساعة بدون نشاط.
- المحاولات الغلط على الكود محدودة (١٢ كل ١٠ دقائق) والإنشاء (٤٠ بالساعة) لكل IP.
